# 8004skill v2.3.3 — Release Notes

> **Release date**: 2026-10-23
> **SDK version**: agent0-sdk v1.7.1
> **Previous version**: v2.3.2

---

## Highlights

Your agent now gets accurate answers about ERC-8004. We re-checked every reference the skill reads against the current EIP-8004 text, the deployed contracts and the SDK. The chain list gains 8 networks and loses 3 that never had the contracts, and the registration and feedback formats now match what actually goes on-chain. No script behavior changes.

---

## Improvements

- **More chains**: Robinhood Chain, Billions, Injective and 0G (mainnets and testnets) join the deployed-chains list. Every chain in the list was verified on-chain.
- **Correct chain list**: Hedera Mainnet, Gnosis Chiado and GOAT Testnet3 were listed but have no ERC-8004 contracts. They are removed.
- **Registration file**: the skill now explains the format other ERC-8004 tools read (`services`, `x402Support`, `registrations`, `supportedTrust`), instead of the SDK's internal shape.
- **Feedback**: the protocol accepts any signed value with decimals. The skill's -100 to 100 scale is now presented as a skill convention, and the skill tells you when a metric such as response time in ms can't be submitted with it.
- **A2A**: agent cards are looked up at `/.well-known/agent-card.json`.
- **Validation Registry**: deployed addresses and current status documented. It remains reference-only until the SDK supports it.

See `CHANGELOG.md` for the full list of corrections.
