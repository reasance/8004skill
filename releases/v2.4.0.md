# 8004skill v2.4.0 — Release Notes

> **Release date**: 2026-10-24
> **SDK version**: agent0-sdk v1.7.1
> **Previous version**: v2.3.3

---

## Highlights

Wallet signing works again: in 2.3.x, WalletConnect pairing failed before showing a QR code, so no write operation could be signed from a wallet app. This release fixes it. Feedback can now also carry the ERC-8004 metrics the spec defines, such as uptime, response time in milliseconds and revenues, not only -100 to 100 ratings.

---

## What's New

### Feedback on the spec's scales

The allowed value now depends on the feedback's first tag, following the ERC-8004 spec:

| tag1 | Allowed value | Example |
|---|---|---|
| none, `starred` | -100 to 100 (quality rating) | `--value 85` |
| `reachable`, `ownerVerified` | 0 or 1 | `--value 1 --tag1 reachable` |
| `uptime`, `successRate` | 0 to 100 (%) | `--value 99.77 --tag1 uptime` |
| `responseTime`, `blocktimeFreshness`, `revenues` | ≥ 0 | `--value 560 --tag1 responseTime` |
| `tradingYield`, custom tags | any value | `--value -3.2 --tag1 tradingYield --tag2 week` |

**Triggers**: "give feedback", "report uptime for agent X", "record response time", "rate agent".

Invalid values (malformed numbers, more than 18 decimals, or too large for the registry) are rejected before your wallet is asked to sign.

---

## Bug Fixes

- WalletConnect: pairing (`wc-pair.ts`) and all WalletConnect-signed operations failed with `EthereumProvider.init is not a function`. Fixed. Headless `PRIVATE_KEY` signing was not affected.
- Feedback: values like `12abc` are no longer accepted as `12`.

## Upgrade Instructions

```bash
npx 8004skill update
```

If pairing failed for you on 2.3.x, run the pairing again after updating: `npx tsx scripts/wc-pair.ts --chain-id <chainId>`, or ask the agent to connect your wallet.
