# 8004skill v2.3.1 — Release Notes

> **Release date**: 2026-10-23
> **SDK version**: agent0-sdk v1.7.1
> **Previous version**: v2.3.0

---

## Highlights

Fixes installation. 8004skill 2.3.0 shipped with `agent0-sdk` pointing at a local development checkout, so installs from npm ended up with a broken SDK link and no script could run. 2.3.1 depends on the published `agent0-sdk@^1.7.1`. No behavior changes.

---

## Bug Fixes

- `agent0-sdk` dependency changed from `file:../../8004.dev/agent0-ts` to `^1.7.1` from npm. In 2.3.0, `node_modules/agent0-sdk` was a symlink to a directory that does not exist outside the maintainer's machine.

---

## Improvements

- **Tests**: SDK integration unit tests for read ops, write ops, A2A and x402 (267 tests total).
