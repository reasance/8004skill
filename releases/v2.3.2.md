# 8004skill v2.3.2 — Release Notes

> **Release date**: 2026-10-23
> **SDK version**: agent0-sdk v1.7.1
> **Previous version**: v2.3.1

---

## Highlights

8004skill has moved to the `reasance` GitHub organization: the repository now lives at https://github.com/reasance/8004skill. This release points the npm package, the installer help text and the docs at the new location. No behavior changes.

---

## Improvements

- **New repository URL**: `package.json` (`repository`, `homepage`), `SKILL.md` and `npx 8004skill` help now link to `reasance/8004skill`.
- **Install commands**: use `npx skills add reasance/8004skill -g` and `git clone https://github.com/reasance/8004skill.git`. The old `matteoscurati/8004skill` URLs still redirect on GitHub.
